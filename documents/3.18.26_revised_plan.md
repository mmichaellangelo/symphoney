# Revised Plan
It's been a while since I've worked on Symphoney and I've had a few ideas since then.  

I'd like to transition the project away from SaaS and towards a self-hosted solution.  

To do this, however, the person running the server must somehow be able to allow inbound connections to their device and that seems like a security nightmare.  

Right now, I'm considering Cloudflare Tunnels as a way to get around this. I'd really like to avoid running a gateway server since at a certain point I'll likely have to shut it down. I'm explorng options right now.  

My idea currently is to keep the project dockerized. This lets me incorporate components like databases (if needed) and something similar to Cloudflare Tunnels.  

Perhaps a setup wizard would be nice. I'm assuming anyone setting up this server has some basic level of computer skills, so I don't think it's incredibly rude to require Docker as a prerequisite.
